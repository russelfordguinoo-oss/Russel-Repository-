Abstract

What characteristics are associated with strong-performing pages?

This study asks which safe page and content characteristics are associated with strong-performing pages in the FlyRank ranking_lifecycle dataset. A page was labeled strong when both its 30-day impressions and clicks were at or above their respective 90th-percentile thresholds, producing 14,972 strong pages out of 205,749 observations. Ten page/content features were evaluated with a client-grouped train/test design, a majority-class baseline, Logistic Regression as the primary model, and Random Forest as a nonlinear robustness comparison. Logistic Regression achieved an Average Precision of 0.0984 against an 8.49% test-set base rate, while Random Forest achieved 0.0877, indicating some measurable association but weak overall discrimination. The result supports diagnostic prioritization rather than causal claims or automatic refresh decisions.

01 · Introduction / Problem Statement

Decision this research supports

Content teams need a practical way to understand which page characteristics are associated with stronger current-state performance without using the performance variables themselves as predictive inputs.

The decision supported by this analysis is: understand characteristics associated with strong-performing pages and use those characteristics to prioritize diagnostic review.

The analysis is observational. It does not establish that changing a page characteristic will cause performance to improve.
02 · Data

Dataset and benchmark

205,749 page observations
34 dataset columns
2,080 90th-percentile impressions threshold
8 90th-percentile clicks threshold

The analysis uses the FlyRank internship-lanes dataset, specifically the ranking_lifecycle subset.

The unit of analysis is the content/page. The analysis uses 30-day performance fields. impressions_30d and clicks_30d are complete in the full dataset. sessions_30d is missing for 26.04% of rows, so it was excluded from the benchmark to avoid requiring a partially observed metric.

A page is labeled strong when both impressions_30d ≥ 2,080 and clicks_30d ≥ 8. This produces 14,972 strong pages, or 7.28% of the dataset.

Pseudonymous identifiers are used only where needed for grouping or ranking output. Client names, domains, URLs, private queries, credentials, and other client-identifying information are excluded from the public paper.

Benchmark composition

03 · Methodology

Clean feature design and grouped validation

Ten predictive features

  • keyword_char_count
  • keyword_token_count
  • public_url_char_count
  • public_url_path_depth
  • content_title_char_count
  • content_title_token_count
  • search_volume
  • content_type
  • main_intent
  • content_age_days

Excluded from predictive features

Performance variables used to construct the label, other performance-derived fields, and pseudonymous identifiers were excluded.

content_created_at was excluded because content_age_days already represents the same temporal information.

Validation design

The final evaluation uses a stratified group split by client_hash_id. Entire clients remain in either the training or held-out test set, preventing client overlap.

156,000 training pages
49,749 test pages
43 training clients
11 test clients

Client overlap was 0. The training strong-page rate was 6.89% and the held-out test strong-page rate was 8.49%.

Preprocessing

Numeric features use median imputation and standardization. Categorical features use most-frequent imputation and one-hot encoding. Preprocessing is fitted within the modeling pipeline using training data only.

Models

The majority-class baseline always predicts not strong.

Logistic Regression is the primary model because it provides interpretable coefficients and probability scores.

Random Forest is a robustness comparison testing whether nonlinear relationships improve discrimination.

Threshold selection

Classification thresholds are selected using five-fold stratified group out-of-fold predictions from the training data only, with F1 as the selection criterion. The selected threshold is then frozen and applied once to the untouched test set.

Interpretation

Logistic Regression improves ranking discrimination relative to the majority baseline, with Average Precision of 0.0984 versus a test-set base rate of 0.0849, or 1.16× lift.

Random Forest produces higher recall and slightly higher F1, but its Average Precision of 0.0877 is only 1.03× the test-set base rate.

Logistic Regression is therefore retained as the primary model. The evidence indicates that the selected content/page features contain some measurable signal, but their combined ability to distinguish strong from non-strong pages is limited.

Error analysis

On the held-out client test set, the primary model produced:

  • 28,798 correct classifications
  • 18,494 false positives
  • 2,457 false negatives

The large number of false positives is consistent with the model's low precision and moderate recall. Error counts should also be interpreted alongside category prevalence.

Observed associations

Logistic Regression coefficients showed associations involving keyword length, URL structure, content title characteristics, search volume, content age, content type, and search intent.

These coefficients describe observed associations within the modeled data. They should not be interpreted as causal effects or as evidence that changing one feature will improve performance.

05 · Limitations & Honest Framing

What this work cannot claim

This analysis is observational and supports decision-making rather than causal inference.

The strong-page label is constructed from current 30-day impressions and clicks, so the model describes current-state association rather than future performance.

The feature set intentionally excludes performance and performance-derived variables that could leak the label. This keeps the experiment methodologically clean but limits predictive information.

Model discrimination is weak. Logistic Regression achieves an Average Precision of 0.0984 against an 8.49% test-set base rate, or 1.16× lift over the base-rate benchmark.

The Top-10 output should therefore be treated as a diagnostic review shortlist rather than an automatic refresh recommendation.

Rare categorical levels were not treated as substantive findings when support was very small.
